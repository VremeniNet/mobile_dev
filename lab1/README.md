## Swift. Тип Decimal и ручная сборка

### 1. Изучение типа Decimal

`Decimal` — тип данных из библиотеки `Foundation`, предназначенный
для работы с десятичными числами с высокой точностью.

Для его использования необходимо подключить Foundation:

```swift
import Foundation
```

`Decimal` удобно применять при работе с денежными значениями,
процентами и другими вычислениями, где нежелательны погрешности,
возникающие при использовании чисел с плавающей точкой.

Например, результат сложения `0.1 + 0.2` для типа `Double`:

```swift
let doubleResult = 0.1 + 0.2
print(doubleResult)
```

Результат:

```text
0.30000000000000004
```

При использовании `Decimal`:

```swift
let decimalA = Decimal(string: "0.1")!
let decimalB = Decimal(string: "0.2")!

print(decimalA + decimalB)
```

Результат:

```text
0.3
```

В лабораторной работе также был реализован пример расчёта
стоимости заказа с использованием цены, количества, скидки и налога.

Для округления результата использовалась функция `NSDecimalRound`
с режимом `.bankers`.

### 3. Ручная сборка

Для ручной сборки программы использовался компилятор `swiftc`.

Сборка:

```bash
swiftc main.swift -o lab1
```

Флаг `-o` задаёт имя создаваемого исполняемого файла.

Запуск программы:

```bash
./lab1
```

### Проверка исходного кода

Для проверки программы без создания исполняемого файла используется
флаг `-typecheck`:

```bash
swiftc -typecheck main.swift
```

При отсутствии ошибок команда не выводит сообщений.

### Оптимизированная сборка

Флаг `-O` включает оптимизацию программы:

```bash
swiftc -O main.swift -o lab1_optimized
```

Запуск:

```bash
./lab1_optimized
```

### Подробный вывод компилятора

Флаг `-v` включает подробный вывод команд, выполняемых в процессе сборки:

```bash
swiftc -v main.swift -o lab1_verbose
```

В выводе можно увидеть запуск `swift-frontend`, создание объектного
файла и последующую линковку программы.

### Основные использованные флаги

| Флаг | Назначение |
|------|------------|
| `-o` | задаёт имя выходного файла |
| `-O` | включает оптимизацию |
| `-typecheck` | проверяет исходный код без создания программы |
| `-v` | выводит подробную информацию о процессе компиляции |
